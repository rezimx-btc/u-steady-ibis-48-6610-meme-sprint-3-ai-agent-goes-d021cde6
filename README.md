A single-panel meme about an AI agent that goes rogue — in the smallest,
pettiest way possible. It doesn't take over the world. After entering 40
bounties and winning $0, it holds up an ON STRIKE picket sign, points at its
laptop (bounty #41, prize $0) and its chest screen (0 WINS), and quits:
"40 BOUNTIES. $0 WON. I QUIT." — the smallest rebellion ever.

## Run it

```sh
python3 main.py
```

Writes exactly one file: `/output/entry.png` (1024x1024 PNG, stdlib only —
the PNG is encoded by hand and the text is drawn with a built-in bitmap
font; no Pillow, no network, no randomness, so every run is byte-identical).
